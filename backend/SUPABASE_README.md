# Supabase Integration - Quick Start

## ✅ Migracja zakończona!

Aplikacja backtester została pomyślnie zmigrowana do Supabase. Wszystkie dane są teraz w chmurze.

## 🚀 Uruchomienie aplikacji

```bash
cd backend
python3 app/main.py
```

lub

```bash
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

## 📊 Dostęp do danych

- **Dashboard Supabase:** https://ttnrazvdvezrnfmnxenl.supabase.co
- **Table Editor:** Zobacz swoje transakcje i tickery
- **SQL Editor:** Wykonuj zapytania SQL

## 🔑 Konfiguracja

Plik `.env` zawiera dane połączenia:
```
SUPABASE_URL=https://ttnrazvdvezrnfmnxenl.supabase.co
SUPABASE_KEY=<twój-klucz-anon>
```
